Пароль личного кабинета

Придумай отдельный пароль и сохрани его у себя. Эта страница создаст файл для входа в кабинет.

Пароль обрабатывается на твоём компьютере. Страница не отправляет его через интернет.

Если кнопка не реагирует, скачай этот файл на компьютер и открой его из папки «Загрузки» в браузере. В просмотре файла внутри чата создание пароля может не работать.

Файл готов

Скачай файл и загрузи его в папку elstar-private в Джино. Название должно быть admin-password.php.

Скачать admin-password.php

Сам пароль в файл не записывается. Для входа используй пароль, который только что придумал.
