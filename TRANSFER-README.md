# ELSTAR — передача проекта для ревью

Работающий сайт: https://elstar-light.ru, хостинг Джино.

Основной исходный проект в этой папке: React 19, TypeScript, Vinext/Vite, Tailwind. Зависимости и версии сохранены в package.json и pnpm-lock.yaml. Требуется Node >=22.13 и pnpm из packageManager. Для локального просмотра: pnpm install, pnpm dev. Часть исходных серверных маршрутов рассчитана на Cloudflare; это прежнее размещение, сейчас основной домен работает на Джино. Не подключайте эти маршруты к production автоматически.

## Версия на Джино

jino-release/ содержит файлы из переданного владельцем архива переноса: готовые JS/CSS, index.html, изображения, PHP-маршруты и копию каталога. Именно эту сборку перенесли на Джино. Здесь нет исходного кода адаптации сборщика для Джино: этот архив содержит готовую сборку, а не воспроизводимый build pipeline. Перед дальнейшими правками другу нужно сопоставить исходный React-проект с JS/PHP этой сборки и восстановить сборку для Джино.

Страница заказа работает через elstar-local-api.php, elstar-local-runtime.php и elstar-local-requests.php. Существующая закрытая папка elstar-private содержит настройки БД и ключи; они НЕ включены. В deploy/jino/ есть шаблоны и исходники приёмника/кабинета прежней интеграции. Не заменяйте ими серверные файлы Джино вслепую. Обновление каталога для Джино находится в deploy/jino/catalog-updater/ и установлено в ~/elstar-private/catalog-updater/. Запускается Python 3.6+, расписание 00:00 и 12:00; ручной запуск проверен 2 октября 2026, первый cron-запуск ещё не подтверждён.

## Подтверждённые ручные изменения на хостинге

Публичные папки assets имеют права 0755, JS/CSS — 0644. index.html заменил заглушку Джино. SSL установлен и HTTPS включён. Основной домен указывает на 195.161.41.13. Покупательские заказы проверены владельцем без VPN с телефона и в кабинете. Telegram не подключён по решению владельца. Временные диагностические страницы и ZIP удалены владельцем из основного webroot.

## Безопасность и публикация

В архиве нет реального config.php, admin-password.php, закрытых ключей, базы покупателей, фотографий клиентов, .git, node_modules, .env и токенов. Публичный ключ ticket-key.php не является секретом. Данные поставщиков и каталога включены для ревью, это не данные покупателей. Полные реквизиты продавца уже публичны на сайте и сохранены в исходниках.

Загрузите проект в PRIVATE репозиторий. Само обновление GitHub не публикует сайт на Джино. Не разворачивайте без проверки резервной копии и адаптации к действующим PHP-маршрутам. Для просмотра другом добавьте его в Settings → Collaborators.
